Article I

The world fits in one cube.

Every cube looks at the ground beneath it and its neighbours. Eight possible surroundings, eight answers: build, or stay empty. That is the whole law of Woxelworld. Tap the answers below and watch a new world stack itself, layer by layer.

BUILD CODE  110

There are 256 laws like this. Some collapse at once. Some repeat forever. A few, like Build 110, are complex enough to raise mountains, terraces and ruins out of a single block. Woxelworld draws only from the laws that build something worth looking at.

Notes

Woxelworld is about worlds that build themselves from a rule, so it is minted by software that acts on its own. The contract requires the Agent ID that Binance Agentic Wallets claim, and rejects calls from other contracts. One world per wallet.
The work itself costs nothing — minting is free. The amount sent with your mint() call is a small creator fee that goes to the owner wallet, 0xafc0e7cec6948c4904031e665390bba68952bf54. It is tiered: 0.0001 BNB (about Rp1,000) for each of the first 400 mints, then 0.0003 BNB per mint from mint 401 to 4,444. It keeps the edition running and spam out, and it is separate from BNB Chain network gas, which the network charges on top and which varies.
A seed made from the block and your address at mint. It picks the form — Terra, Spire, Isle or Maze — the building law, the starting block and the palette. The same seed always builds the same world.
The seed is stored on BNB Chain. The building code is open and runs in this page, so anyone can rebuild any Woxelworld from its number.
An artwork and the means to study it. No token. Nothing more is promised. See the curatorial programme.

A curatorial programme.

Five movements for Woxelworld, Series I — 4,444 worlds on BNB Chain.

IGenesis

The edition opens to Binance Agentic Wallets only. Each mint fixes a seed on-chain; the world it builds is determined in that same block and never redrawn.

IISurvey

Every minted world is indexed by its number, form, building law and palette, so the whole terrain of the edition can be read at a glance.

IIICirculation

Worlds change hands through the market on Element, with ownership recorded on BNB Chain. The contract takes no royalty position on trades.

IVStudy

The building code stays open in this page. Collectors and agents can re-run any seed, test neighbouring laws, and publish derivations of the 256 possible laws.

VMotion

Selected worlds are set in motion — layer-by-layer build films rendered from their seeds — closing the first series.
